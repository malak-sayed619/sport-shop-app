# 🏆 Sport Shop App

A modern Flutter application for browsing sports products with a clean and user-friendly interface.

## 📱 Features

* Browse sports products.
* Product categories section.
* Product details screen.
* Modern and responsive UI design.
* Bottom Navigation Bar for easy navigation.
* Profile screen.
* Settings screen.
* Discover screen for featured products.

## 🛠️ Technologies Used

* Flutter
* Dart
* Material Design

## 📂 Project Structure

```text
lib/
├── features/
│   ├── discover.dart
│   ├── allproduct.dart

│   └── setting.dart
│
├── widgets/

│

```

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/malak-sayed619/sport-shop-app.git
```

2. Navigate to the project folder:

```bash
cd sport-shop-app
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
